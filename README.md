# Resume Generator (Servlet + HTML)

A simple Java web application that allows users to generate and download their resume as a `.txt` file. Built using **Java Servlets**, **HTML5**, **Bootstrap**, and deployed using **Apache Tomcat** in **Eclipse IDE**.

## 🛠️ Technologies Used

* Java (Servlets)
* HTML5 + CSS3 (Bootstrap 5.3)
* Eclipse IDE (with Dynamic Web Project)
* Apache Tomcat (v10+)
* Jakarta Servlet API

## 📂 Project Structure

```
ResumeGenerator/
├── WebContent/
│   └── index.html              # Frontend form
├── Java Resources/
│   └── demopackage/
│       └── demoServlet.java    # Backend Servlet
└── WEB-INF/
    └── web.xml (auto-managed if using annotations)
```

## 🚀 How It Works

1. User fills out the resume form on `index.html`.
2. Upon form submission, a POST request is sent to `/demoServlet`.
3. `demoServlet` processes input, sanitizes it, and generates a `.txt` resume.
4. User receives a downloadable `.txt` resume with the provided information.

## 📥 Features

* Clean Bootstrap UI form.
* Input sanitization for security.
* Resume generated in `.txt` format.
* Optional LinkedIn field.
* Easy to deploy and extend.

## 🧑‍💻 How to Run Locally

### Prerequisites

* Eclipse IDE with **Java EE/Web Tools**
* Apache Tomcat v10+ installed and configured in Eclipse

### Steps

1. **Create a Dynamic Web Project**

   * File > New > Dynamic Web Project
   * Name: `ResumeGenerator`
   * Target runtime: Apache Tomcat
   * Configuration: Java EE 8 or Jakarta EE

2. **Add Servlet**

   * Create package: `demopackage`
   * Add `demoServlet.java` with the provided servlet code.

3. **Add Frontend**

   * Place `index.html` inside `WebContent/`

4. **Run the Project**

   * Right-click the project > Run As > Run on Server
   * Open browser at: `http://localhost:8080/ResumeGenerator/index.html`

5. **Fill the form and click "Generate & Download Resume"**

## 📌 Notes

* Servlet is mapped using `@WebServlet("/demoServlet")`, no need to edit `web.xml`.
* Ensure Jakarta Servlet libraries are included if using Tomcat 10+.
* Use UTF-8 encoding throughout to support special characters.
